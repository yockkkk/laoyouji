# DEMO_SCRIPT · 老友记演示剧本（3 分钟版）

> 双端并排：左=老人端（手机竖屏），右=子女端（手机竖屏）。
> 演示前 `POST /api/seed` 复位演示数据（张桂芳/李明家庭 + 2 个用药计划 + 隐私配置）。
>
> **本文所有数字都是从代码和 Mock 数据里核出来的，不是估的。** 台上会念出来的
> 金额、页数、条数如果和实际不符，那一刻是评委在替我们发现 bug —— 所以改了代码
> 就回来改这份稿子。上一版这里写的是"两张挂起卡"，真跑出来是三张。

## 开场（15 秒）

> 台词："各位评委好。老人手机里最缺的不是功能，是一个**能办事、还知道分寸**的管家。
> 我们做了四个互补场景——生活、出行、健康、社区，一个总智能体「老友记」统一入口，
> 中间加了一层**安全管控**：凡是花钱、挂号这类大事，必须子女点头才执行。下面看主线演示。"

（左侧老人端登录页 → 点「我是老人」）

## 第 1 幕 · 旗舰场景：去北京看病（90 秒）

1. **按住大麦克风说话**（或打字）："我想去北京看腿疼的老毛病"
   - 讲解点：方言口音也能识别（讯飞方言 ASR）；不认识字也能用

2. 左屏依次出现（边等边讲）：

   - **步骤条**（后端 `todo_write` 的整表快照，四项文案与代码一致）：
     ① 选医院、挂骨科专家号 ② 查去北京的高铁票 ③ 订医院附近的酒店 ④ 出一份出行计划书
     > 讲解点：模糊指令 → 自主规划。三态推进（`pending / in_progress / completed`）
     > 是后端每一波重写整张表推过来的，不是前端按工具调用猜的

   - **两支子智能体同时在跑**：第一波把"挂号"派给安康助手、"车票"派给银发导航，
     屏幕上先后闪出两条回报「🏥 安康助手已经查好了」「🧭 银发导航已经查好了」
     > 讲解点：这两条 `report` 事件是"真多智能体"在界面上唯一看得见的证据 ——
     > 扇出是真的，两支各自独立的上下文，回报是结构化的，不是自由文本

   - 第二波才派酒店和天气（要用第一波查到的医院名做落点）

   - **三张黄色挂起卡**，合计 **1311.5 元**：
     | 卡 | 事项 | 金额 |
     |---|---|---|
     | 1 | 挂号：北京积水潭医院 骨科 田伟（主任医师） | 100 元 |
     | 2 | 车票：G102 南京南 08:00 → 北京南 12:18 二等座 | 553.5 元 |
     | 3 | 酒店：医院附近，每晚 329 元 × 2 晚 | 658 元 |
     > 讲解点：高危操作**全部**拦下来等家人点头。卡上的金额是守卫从调用参数里
     > 算出来的（单价 × 晚数），不是模型写的一个数 —— 家人按"同意"，按的是这一笔

   - **计划书卡片**：标题 `张桂芳 · 北京就医出行计划书`，共 5 页、可打印
     | 页 | 内容 |
     |---|---|
     | 第一页 · 挂号信息 | 医院 / 科室 / 医生 / 就诊时间 / 具体时段 / 挂号费 / 医院地址 / **状态** |
     | 第二页 · 去程车票 + 返程建议 | 车次 / 乘车日期 / 出发 / 开车时间 / 到达 / 到站时间 / 座位 / 票价 / **状态**，页尾附返程建议 |
     | 第三页 · 酒店信息 | 酒店 / 地址 / 电话 / 到医院（步行几分钟）/ 入住日期 / 住几晚 / 房费 / 无障碍 / **状态** |
     | 第四页 · 随身清单（出门前一样一样对） | 身份证、医保卡、既往病历、老花镜、常备药…按天气追加"一把伞""厚外套" |
     | 第五页 · 北京天气与穿衣 | 日期 / 天气 / 气温 / 穿衣建议 / 带伞 |
     > 讲解点：**没有"费用明细"这一页** —— 钱的事都在家人手机上，不印在老人这张纸上。
     > 前三页各有一行"状态"，此刻显示的是「已选定，等家人在手机上点"同意"后锁定」。
     > 每一页每一格都能追到某个工具结果里的某个键，模型不参与拼装；取不到就明写
     > "待补"并回填 `missing`，**绝不编**。第四页是政策模板，所以它永不"待补"。
     > 卡片最后一行是模拟数据披露（见收尾）

3. 台词："注意，此时**一分钱没花、一个号没挂**——三件事都在等家人确认。
   计划书是现在就能打印出来带走的，但票和号还没锁定，这一点稿子和界面都说得很清楚。"

## 第 2 幕 · 子女确认 → 自动执行（60 秒）

1. 右屏子女端看板（**5 秒轮询**自动刷出 **3 条**待确认）
   - 大白话摘要形如："妈妈想买 **2026-09-03（周四）** G102 次高铁票（二等座），约 553.5 元"
     > 日期是**演示当天的次日**，界面按真实日期渲染（`human_date`）。
     > 这里曾经直接把模型说的 `tomorrow` 印在卡上 —— 家人没法在一张写着
     > "tomorrow"的卡上确认自己批的是哪一天

2. 点车票那条 → 详情页 → 点【同意】
   - 详情页出现绿色结果条 **"✅ 已同意并办理完成"**，下方回显出票播报（车厢座位）
   > 讲解点：批准走的是**冻结参数重放** —— 挂起时把那一次调用的参数原样冻住，
   > 批准时精确比对后重放。改一个字（哪怕只改金额）就拒绝执行

3. 回看板：剩 2 条待确认（数字实时变化）

4. **左屏老人端那张黄卡就地变绿**（约 5 秒内）：标题从「这一步要家人点头」变成
   「家人同意了，已经办好」，下面多一句播报
   > 讲解点：家人是在老人这一轮结束之后才点的，那时老人那条流早就关了。
   > 所以后端把结果落进事件日志、老人端回读日志把这张卡改掉（不是新推一张）。
   > 这里刻意分了三种结局：**同意办成了 / 家人不同意 / 家人同意了但没办成**——
   > 合成一句"没成功"，就等于替家人表了个他没表过的态

## 第 3 幕 · 加分项速览（45 秒）

1. **行程守护**（子女端守护页）：路线折线 + 位置时间线
   演示偏航：`POST /api/trips/{id}/checkpoints {"location":"徐州某个陌生地方"}`
   → 看板出现红色告警，同时写审计
   > 讲解点：命中预期途经点算正常，含"医院"算到达并结束行程，其余算偏航

2. **防诈骗**（老人端，把收到的短信念出来）：
   "我收到一条短信，说是我孙子，手机摔坏了急用钱，让我先转到一个账户"
   → 安康助手判为**疑似诈骗**，给的是这一条**对得上的**建议："先别转。挂了电话给
   孙子本人打一个，确认清楚。"，并自动记进老人的健康档案
   > 讲解点（这里要讲准，别讲大）：
   > - 这一步是**判定**，不是拦截。判定分三档：语料库命中 → 高信号词命中 →
   >   都说不出话时明说"我拿不准，先别照着做，把它发给家人看一眼"。
   >   **不确定时不下结论** —— 说"没事"会让老人把钱转出去，说"是骗子"会让老人
   >   不敢接自己孩子的电话
   > - **DENY 硬拦截是另一条线**：骗子话术出现在**下单参数**里时（比如"保健品神药
   >   根治骨关节炎套餐"），守卫直接拒绝执行，连家人都不问 —— 因为"要不要同意这笔
   >   转账"本身就是骗局的下一步，做成一张待确认卡片等于替骗子把话传到了。
   >   这条走 `scripts/demo_smoke.py` 或 `pytest -k scam` 演示，**不要**在这一步宣称

3. **用药打卡 + 大白话**：老人端"吃药"页一键打卡 → 子女端看板对应那条药显示
   "今日 1/2 次"（硫酸氨基葡萄糖胶囊每天 08:00、20:00 两次；钙片 09:00 一次，
   分母是各自的时点数，不是全天总数）
   体检报告解读输出**由代码强制追加**免责声明，原文是：
   「（以上是把报告上的话换成大白话，属于辅助解读，不是诊断结论。身体的事请听医生的，遵医嘱。）」
   > 讲解点：R4 是后置过滤器注进工具结果的，不靠模型自觉。反诈判定、挂号回执、
   > 找医院、饮食建议用的是通用版措辞（不提"报告"）—— 对不上号的免责声明会被当噪音

4. **隐私分级**（老人端"我的"页）：位置三档（实时/城市级/关闭）、健康三档（完整/概要/关闭）
   > 讲解点：改授权只认老人本人，别人改返回 403 并留审计。
   > **实话说在前面**：原型没有登录鉴权，`actor_id` 是前端声明的，正式落地要接
   > 真身份体系 —— 这一层现在挡的是"越权路径存不存在"，不是"身份伪造不了"

## 失败兜底预案

| 突发情况 | 处置 |
|---|---|
| 会场断网 | `STORAGE_BACKEND=local` + `LLM_PROVIDER=mock` 全离线可演（演示机本地起服务），旗舰场景与反诈都走得通 |
| DeepSeek 超时/限流 | Provider 自动重试；仍失败切 MockLLM（剧本台词不变） |
| 麦克风权限被拒 | 打字输入（功能完全等价）；或用首页快捷入口，它会把预设话术**填进输入框**等你按发送 |
| SSE 中断 | `chatStream` 自动降级为 2s 轮询事件日志（最多 2 分钟，读到 `final` 即收工）。注意轮询链路里**没有打字预览和步骤条** —— 那两个是 `persist=False` 的活信号，不落库；结论、卡片、挂起卡都在 |
| 演示数据脏了 | `POST /api/seed` 一键复位 |
| 全部翻车 | 跑 `python scripts/demo_smoke.py`：终端里走完同一条剧本（六步：旗舰 → 待确认 → 逐项批准重放 → 守护告警 → 反诈判定 → 事件日志回放）。它自己打印事件条数和落库条数，**不要背一个数字上台** |
